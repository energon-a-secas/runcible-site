Template UI kit

Sections use .section + .stack for rhythm. Cards are calm by default; add .card--interactive only for hover lift. Blocking overlays use .modal; the auth strip is a sheet (no backdrop), not a modal.

Ghost link

Default card: subtle border/shadow on hover, no floaty lift. Use for dense forms and content.

Interactive card: reserved for primary surfaces you want to feel tactile (hero picks, featured modules).

Buttons

Canonical classes: .btn + .btn--primary, .btn--secondary, .btn--ghost, .btn--danger, plus optional .btn--sm, .btn--block, or .btn--icon.

Example modal

Use modals for blocking tasks. Sheets (collapsible rows under the header) keep context visible, see commented .auth-panel in index.html.
Runs entirely in your browser.
